# fonts — refinement ideas

**Today:** Pobeda 3.5, an original monospace font drawn in code by
`build_pobeda.py` (fontTools TTGlyphPen) into `pobeda.ttf`. It covers
ASCII and Russian Cyrillic, box drawing, blocks and shades, and Russian
punctuation. It is marked fixed-pitch with one line height on every
platform. Mbltishi and the Moscow terminal use it.

## Coverage
- Full Cyrillic: Ukrainian (Ґ Є І Ї), Belarusian (Ў), Serbian and
  Macedonian (Ђ Ј Љ Њ Ћ Џ Ѓ Ќ), Kazakh, and old letters (Ѣ Ѳ Ѵ І) for
  pre-reform text
- Latin-1 Supplement and Latin Extended-A (Western and Central European
  accents)
- Greek (for maths and science)
- Arrows, maths operators (≤ ≥ ≠ ∞ √ ∑ ∫), currency symbols (₽ € £ ¥)
- The full Box Drawing block (rounded corners ╭╮╯╰, heavy and light
  mixes, dashed lines) and Block Elements (eighths for progress bars)
- Braille patterns (terminal graphs) and Powerline/private-use glyphs
  for prompts
- Card suits ♠ ♣ ♦ ♥ (Sochi prints them)
- Legacy computing symbols (U+1FB00) for TUI graphics

## Styles
- Bold, italic (or oblique) and bold italic faces, generated by the
  same script with stroke width and slant parameters
- Light and medium weights, or a variable font with a weight axis
- A condensed width for dense panels

## Code features
- Distinct 0/O, 1/l/I and rn/m, checked with a confusables test page
- Optional ligatures (`->`, `<=`, `!=`, `:=`) as an OpenType feature,
  off by default
- Stylistic sets: slashed or dotted zero, alternate Д/д forms
- USSR-specific glyph tuning for `[ ] { } ( ) :` (the language's core
  punctuation)

## Engineering
- TrueType hinting (ttfautohint) for crisp small sizes on Windows
- Kerning is not needed (monospace), but check `hmtx` and advance widths
  in a test
- Bitmap strikes (embedded) for 12–16 px terminal use
- WOFF2 output for web pages (Novgorod could use Pobeda for code blocks)
- A specimen generator: a PDF/PNG page of every glyph at several sizes
- Automated checks with fontbakery and fontTools validation in CI
- A glyph coverage report against the Unicode blocks above
- Version metadata and changelog inside the font's `name` table
- Fill in the license in `box.uno` (UNSPECIFIED today); SIL OFL is the
  usual choice for fonts

## Integration
- A Petersburg default UI font option (outline fonts are already
  supported)
- Install scripts for Windows, Linux and macOS user font folders
- Packaging through Ural with the `.ttf` listed in `files`
