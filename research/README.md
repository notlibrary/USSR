## Refining and enrichment

Refining is a prompt operation 
prompt A: "Make a text editor"
Task A: supports bold text"
prompt B: "Make the text editor which supports bold text

*Refining* is sequential improving of the prompt until it reflects reality
it can be done by writing an initial good prompt or prompting sub-tasks against neuroslop output from user prompt

*Enrichment* is choosing the better answer from multiple models used multiple times using "what is better"
test suite while making this suite requires less intelligence than solving problem itself and sequential transfer current best 
solution to the next model or iteration with current model until reached the best option that tests can detect
