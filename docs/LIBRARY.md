## args.su

```
args.su - a command-line argument parser, in USSR.
Declare the options, then parse init's arg_vec:

  args_new(p): "tool" "Does a thing."
  args_flag(_): p "verbose" "v" "print more"
  args_option(_): p "out" "o" "FILE" "where to write" "out.txt"
  args_parse(a): p arg_vec 1          # 1: skip the program name
  args_get(v): a "out"                # "out.txt" or what was given
  args_has(b): a "verbose"            # true when -v / --verbose came
  args_rest(v): a                     # the positional arguments
  args_error(e): a                    # "" or why parsing failed
  args_help(text): p                  # the generated --help text

Accepted forms: --name value, --name=value, -o value, -ovalue, -abc
(several flags), and -- to end the options. A "-h"/"--help" sets the
flag "help". Unknown options and a missing value set args_error.
Parsers and results are btrees; options are kept in declaration order.
```

## bytes.su

```
bytes.su - byte-vector serialization and memory filling.
Native VM primitives owned by this module (memset analogs):
  set_bytes(v): value vec  -> every item of vec := value (0..255),
                              like memset(vec, value, sizeof vec)
  clear_bytes(v): vec      -> set_bytes with value 0
  read_bytes(v): "path"    -> the file's bytes as a vector (null if
                              unreadable); NUL bytes are kept
  write_bytes(n): "path" vec -> write exactly vec's bytes 0..255;
                              bytes written, or -1 if it cannot
  text_bytes(v): "text"    -> the string's bytes as a vector
serialize(v): value "INT"    -> v becomes 8 little-endian bytes of value
deserialize(v): bytes "INT"  -> v becomes the integer stored in bytes
Only "INT" is supported; other tags return null.
```

## dates.su

```
dates.su - calendar arithmetic and date formatting, in USSR.
Dates are proleptic Gregorian. "Unix days" count days since 1970-01-01;
a time(s): value divided into days gives one. All in UTC unless a
localtime(t): vector is passed in.
  is_leap_year(r): y          -> true for Gregorian leap years
  days_in_month(r): y m       -> 28..31
  days_from_civil(r): y m d   -> Unix days for a date
  civil_from_days(v): days    -> [year month day]
  day_of_week(r): y m d       -> 0 (Sunday) .. 6
  day_of_year(r): y m d       -> 1..366
  gmtime(v): seconds          -> [year month day hour minute second
                                 weekday yearday], like localtime(t):
  timegm(r): v                -> seconds from such a vector (UTC)
  iso_date(r): v              -> "2026-11-16" from a time vector
  iso_datetime(r): v          -> "2026-11-16T09:05:00" from a time vector
  iso_utc(r): seconds         -> "2026-11-16T09:05:00Z"
  iso_parse(r): text          -> seconds for "YYYY-MM-DD", with an optional
                                 "THH:MM[:SS]" and "Z" or "+HH:MM"; null if
                                 the text is not such a date
  strftime(r): format v       -> %Y %m %d %H %M %S %y %j %a %A %b %B %e %%
  month_name(r): m / day_name(r): wd   English names
  elapsed_ms(r): start        -> milliseconds since a clock_ms(s): value
  clock_ms(r):                -> a millisecond clock for timing; it has
                                 the resolution of time(s): (seconds)
                                 unless the host offers better
```

## encoding.su

```
encoding.su - text and byte encodings and small checksums, in USSR.
Byte data is a vector of 0..255 values (see bytes.su); text is a string.
Functions that take "data" accept either a string or a byte vector.
  base64_encode(r): data         -> standard alphabet with "=" padding
  base64url_encode(r): data      -> URL alphabet (- and _), no padding
  base64_decode(v): text         -> byte vector; both alphabets, padding
                                    optional, blanks skipped; null when a
                                    character is invalid
  base64_decode_text(r): text    -> the decoded bytes as a string
  hex_encode(r): data            -> lower-case hex digits
  hex_decode(v): text            -> byte vector, null on odd length or a
                                    bad digit
  url_encode(r): text            -> percent-encoding of everything but
                                    A-Z a-z 0-9 - _ . ~
  url_decode(r): text            -> %XX decoded, "+" becomes a space
  form_encode(r): pairs          -> "a=1&b=x%20y" from [[k,v],...]
  query_parse(v): text           -> [[k,v],...] from "a=1&b=x+y"
  fnv1a32(r): data               -> 32-bit FNV-1a hash
  adler32(r): data               -> Adler-32 checksum (zlib)
  crc32_hex(r): data             -> the builtin crc32 as 8 hex digits
  sha256_hex(r): data            -> the builtin sha256 as 64 hex digits
  md5_hex(r): data               -> the builtin md5 as 32 hex digits
  uuid4(r):                      -> a random version-4 UUID string
  uuid_valid(r): text            -> true for 8-4-4-4-12 hex text
```

## io.su

```
io.su - basic I/O library for USSR.
Native VM primitives owned by this module:
  template(ok): "TYPE;TYPE;..." value...   (printf-style output)
  scan(ok): "prompt TYPE;TYPE;..." dest... (line/token input)
  open_file(h): "path" "mode"              (stream open, h >= 0 or -1)
    mode is a C fopen mode: "r" "w" "a" "rb" "wb" "ab"
    (and the "+" update variants r+ w+ a+ rb+ r+b ...)
  close_file(ok): h                        (stream close)
  write_file(n): h "text"                  (bytes written)
  read_file(s): h [n]                      (rest of file, or n bytes)
  read_line(s): h                          (next line without LF/CRLF,
                                            null at end of file)
  write_stderr(n): "text"                  (text to standard error as
                                            is, bytes written)
Directory and path primitives (0 ok / 1 failed results are non-fatal):
  list_dir(v): "path"     names sorted without regard to case; directory
                          names end in "/"; null if unreadable
  is_dir(b): "path"       1 for a directory, 0 otherwise
  getcwd(s):              current working directory
  make_dir(ok): "path"    create one directory (fails if it exists)
  rename_path(ok): from to   move/rename; never replaces a destination
  copy_file(ok): from to     copy one file's bytes; never replaces a
                             destination; directories are refused
  remove_file(ok): "path" delete a file (directories are refused)
  remove_dir(ok): "path"  delete an empty directory
These are real stream operations on open handles; the whole-file
readfile/writefile VM builtins stay available separately.
Library-provided helpers:
  putch(ok): code                          (write one byte/char)
  getch(code):                             (read one char, -1 at EOF)
No top-level state: programs with init(...) skip top-level commands.
```

## json.su

```
json.su - a JSON reader and writer, in USSR.
JSON maps onto USSR values: objects become btrees (string keys, so they
come back sorted by key), arrays become vectors, and strings, numbers,
true, false and null become themselves. Numbers with a fraction or an
exponent are reals, others integers.
  json_parse(v): text        -> the value, or null with json_error set
                                (json_parse of "null" also gives null:
                                check json_error(e): when it matters)
  json_error(r):             -> "" after a good parse, else the reason
                                and the byte offset
  json_stringify(r): value   -> compact JSON text
  json_pretty(r): value indent -> the same with newlines and `indent`
                                spaces per level
  json_get(r): value path    -> walks "a.b.0.c" through objects and
                                arrays; null when a step is missing
Strings are UTF-8; \uXXXX escapes (with surrogate pairs) decode to UTF-8,
and the writer escapes only what JSON requires. A NUL (\u0000) cannot
live in a USSR string and is an error.
```

## lists.su

```
lists.su - vector helpers, written in USSR.
Vectors grow with push and shrink with pop; these build new vectors for
everything else, so the input is never changed unless the name says so.
  list_range(v): from to step  -> from, from+step, ... before `to`
  list_copy(v): v              -> a shallow copy
  list_reverse(v): v           -> items in reverse order
  list_slice(v): v from count  -> count items from index from (clipped)
  list_concat(v): a b          -> a's items, then b's
  list_index_of(r): v item     -> first index of item, or -1
  list_contains(r): v item     -> true when item is in v
  list_count(r): v item        -> how many times item occurs
  list_unique(v): v            -> first occurrences only, order kept
  list_insert(v): v index item -> a copy with item placed at index
  list_remove_at(v): v index   -> a copy without the item at index
  list_remove(v): v item       -> a copy without any item equal to item
  list_set(v): v index item    -> a copy with index replaced by item
  list_sort(v): v              -> ascending; numbers by value, strings by
                                  bytes (a stable merge sort)
  list_sort_desc(v): v         -> descending
  list_sort_natural(v): v      -> strings in natural order (file2, file10)
  list_min(r): v / list_max(r): v -> smallest / largest item, null if empty
  list_zip(v): a b             -> [[a0,b0],[a1,b1],...] up to the shorter
  list_flatten(v): v           -> one level of nested vectors spliced in
  list_chunk(v): v size        -> vectors of size items (the last shorter)
  list_fill(v): item count     -> count copies of item
  list_equal(r): a b           -> same length and equal items
  list_take(v): v n / list_drop(v): v n
Set operations on vectors of numbers or strings (order of a kept):
  set_union(v): a b / set_intersect(v): a b / set_difference(v): a b
A queue and a stack over vectors:
  queue_new(q): / queue_push(_): q item / queue_pop(r): q / queue_len(r): q
  queue_pop gives null when the queue is empty. Queues live in a btree
  (items under integer keys, "head" and "tail" counters), so both ends
  are cheap and no struct declaration is needed (libraries must not
  rely on top-level commands, which init programs skip).
A priority queue (lowest priority first, FIFO among equals):
  heap_new(h): / heap_push(_): h priority value / heap_pop(r): h
  heap_pop gives [priority, value] or null; heap_len(r): h
```

## math.su

```
math.su - numeric helpers.
Constants arrive as preprocessor macros:
  M_PI, M_E
Library-provided functions (pure USSR):
  sqrt(r): x      -> Newton iterations, -1 after error for x < 0
  sin(r): x       -> range-reduced fitted polynomials, radians
  cos(r): x       -> same reduction, radians
  ln(r): x        -> atanh series, x > 0 (0 after error otherwise)
  exp(r): x       -> range-reduced series
  pow(r): x y     -> exp(y * ln(x))
  floor(r): x     -> largest integer <= x
  ceil(r): x      -> smallest integer >= x
  atan(r): x      -> inverse tangent via reduction + Taylor series
  asin(r): x      -> atan(x / sqrt(1 - x^2)), |x| <= 1
  acos(r): x      -> pi/2 - asin(x), |x| <= 1
  atan2(r): y x   -> angle of point (x, y) in (-pi, pi]
```

## paths.su

```
paths.su - path, file and environment helpers over io.su's primitives.
Paths use "/" on every platform; a "\" is read as "/" too, so Windows
paths work. A drive prefix ("C:") is kept as part of the root.
  path_join(r): a b          -> a and b with one "/" between; an absolute
                                b replaces a
  path_join_all(r): v        -> path_join over a vector of parts
  path_dir(r): p             -> everything before the last "/" ("." if none)
  path_base(r): p            -> the last part
  path_ext(r): p             -> ".su" style extension of the last part, or ""
  path_stem(r): p            -> the last part without its extension
  path_is_abs(r): p          -> starts with "/" or a drive letter
  path_normalize(r): p       -> "." and ".." resolved, "//" collapsed
  path_abs(r): p             -> joined to getcwd(s): when relative
  path_split(v): p           -> its parts, without empty ones
  exists(r): p               -> true for a file or a directory
  read_lines(v): path        -> lines without their LF/CRLF, null when
                                the file cannot be opened
  write_lines(r): path v     -> the lines, each ending in LF; 0 or -1
  append_line(r): path text  -> text and a LF at the end of a file
  read_text(r): path / write_text(r): path text
  write_file_atomic(r): path text -> writes path.tmp, then renames it over
                                path (0 ok, -1 failed)
  walk_dir(v): dir           -> every file below dir, as paths, sorted
  glob(v): pattern           -> files matching a pattern with * ? and **
  glob_match(r): pattern path -> the matcher glob uses
  copy_dir(r): from to       -> copies a tree; never replaces files
  remove_tree(r): dir        -> deletes a tree; refuses "", "/" and
                                drive roots; 0 ok, -1 failed
  temp_dir(r):               -> TMPDIR, TEMP, TMP or /tmp
  temp_path(r): prefix       -> a fresh name in temp_dir (not created)
  env_get(r): name default   -> getenv, or default when unset
  env_expand(r): text        -> $NAME, ${NAME} and ~ at the start
                                expanded; unset names give ""
  env_path_list(v):          -> PATH split at ";" on Windows, ":" elsewhere
  which(r): program          -> the first PATH entry holding program (on
                                Windows also with .exe, .bat, .cmd), or null
```

## standard.su

```
standard.su - core VM services exposed as part of the standard library.
Native VM primitives owned by this module:
  random64(r):              -> next 64-bit pseudo-random integer
  seed_random64(ok): seed   -> seed the PRNG and echo the seed
  time(r):                  -> current UNIX time in seconds
They are implemented by the interpreter/VM; this file anchors them in
the standard library so user code has one stable place to rely on.
```

## strings.su

```
strings.su - text and number formatting helpers, written in USSR.
Library-provided functions (pure USSR, no native code):
  str_from_int(r): n            -> decimal text of an integer
  str_trunc(r): x               -> integer part of a number, toward zero
                                   (USSR "/" always yields a real; use
                                   str_trunc(q): {a / b} for integer
                                   division of exact quotients)
  str_from_number(r): x digits  -> x rounded to `digits` decimals; trailing
                                   zeros (and a bare ".") are dropped, so
                                   whole values print as integers
  str_to_number(r): s           -> integer or real parsed from decimal text
                                   with optional sign, fraction and
                                   exponent; surrounding blanks are ignored;
                                   null when s is not a number
  str_lower(r): s               -> copy with ASCII letters in lower case
  str_find(r): s needle from    -> first index >= from of needle, or -1
  str_trim(r): s                -> s without leading/trailing blanks
                                   (space, tab, CR, LF)
  str_repeat(r): s count        -> s repeated count times
  utf8_* helpers (end of file)  -> step through UTF-8 text by character
  str_int_limit(r):             -> largest value str_trunc accepts: 2^62
                                   (integers are 64-bit everywhere; the
                                   margin keeps str_trunc's sums in range)
str_from_number lowers `digits` when x * 10^digits would pass that limit,
so very large values print with fewer decimals instead of overflowing.
Temporaries use the _str prefix; parameters are restored after each call.
```

## testing.su

```
testing.su - a small test helper shared by tests/ and subprojects.
Every check prints "PASS label" or "FAIL label (got X, want Y)" and
counts; test_summary prints the totals and returns the failure count,
so a script can end with `test_summary(n):` and exit with n.
  assert_eq(r): label got want        -> true when equal (values of
                                         different kinds are unequal;
                                         vectors compare item by item)
  assert_true(r): label value
  assert_near(r): label got want eps  -> |got - want| <= eps
  assert_null(r): label value
  test_reset(_): / test_counts(v): -> [passed failed]
  test_summary(r):                    -> prints "N passed, M failed"
Counters live in the !-hash namespace, so they work in init programs and
across processes.
```

## textproc.su

```
textproc.su - templates, escaping, line diffs and logging, in USSR.
  html_escape(r): s          -> & < > " ' as entities
  sql_quote(r): s            -> a SQL string literal, quotes doubled
  shell_quote(r): s          -> one POSIX shell word in single quotes
  template_render(r): text values mode
                             -> ${name} holes filled from a btree of
                                values; mode "html", "sql", "shell" or
                                "" (none) escapes each value; $$ is a
                                literal $; a missing name stays as is
  diff_lines(v): a b         -> an edit script between two vectors of
                                lines (longest common subsequence):
                                items are "  line", "- line", "+ line"
  diff_unified(r): a b name_a name_b
                             -> unified-diff text with 3 lines of context
  patch_apply(v): a script   -> b again, from a and a diff_lines script;
                                null when the script does not fit a
  log_level(_): name         -> "debug", "info", "warn" or "error"
                                (default "info"); lower ones are dropped
  log_file(_): path          -> also append every message to path
                                ("" stops)
  log_debug(_): msg / log_info(_): msg / log_warn(_): msg / log_error(_): msg
                             -> "2026-11-16T09:05:00Z WARN msg" on stderr
```

## vectors.su

```
vectors.su - 2D and 3D math vectors.

The types are built into the runtime as structs, so new/getf/setf, UNO
literals and encode/decode work without this file:
  Vec2{x, y}    Vec3{x, y, z}      (number fields)
  new(p): "Vec2" 1 2      set(q): 'Vec3{x=1,y=2,z=3}'
The VM implements these operators inside { }:
  {a + b} {a - b}   same dimension only
  {v * k} {k * v} {v / k}   scaling by a number (k != 0 for /)
  {a = b} {a != b}  component-wise; vectors of different dimension differ
Anything else (adding a number, mixing Vec2 and Vec3, v * v, a < b, ...)
stops with an error naming both operands.

Library-provided functions (pure USSR; errors stop the script via fail):
  vec2(v): x y         vec3(v): x y z          -> new vector
  vdim(n): v           -> 2 or 3
  vget(c): v i         -> component i (0 = x, 1 = y, 2 = z)
  vset(v): v i value   -> sets component i, returns v (vectors are shared
                          references, like all structs)
  vadd(v): a b   vsub(v): a b   vscale(v): v k   vneg(v): v
  vdot(n): a b         -> dot product
  vcross(c): a b       -> Vec3 for two Vec3; for two Vec2 the number
                          a.x * b.y - a.y * b.x (z of the 3D product)
  vlen(n): v           vdist(n): a b           vnorm(u): v (v != 0)
  vlerp(v): a b t      -> a + (b - a) * t
  vnear(b): a b eps    -> true when every component differs by <= eps
  vstr(s): v           -> "(1, 2)" / "(1, 2, 3)", up to 6 decimals
```
